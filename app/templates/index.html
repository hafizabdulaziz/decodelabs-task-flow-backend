  2. Login to obtain JWT token via Panel 1 (POST /api/v1/auth/login). The token is automatically injected into the global header bar.
  3. Test task CRUD operations in Panel 2.
  4. Test external weather integration in Panel 3.
  5. Use AI Chat Assistant widget at bottom-left for natural language control.
