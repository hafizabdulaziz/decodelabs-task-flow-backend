  1. Register a new account via Section A (POST /api/v1/auth/register).
  2. Login to obtain JWT token via Section A (POST /api/v1/auth/login). The token is automatically injected into the global header bar.
  3. Test user profile in Section B and task CRUD operations in Section C.
