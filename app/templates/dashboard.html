Embedded API Documentation & Guide

Decodelabs Task Flow API is engineered with FastAPI, Async SQLAlchemy, and PostgreSQL.

Key Endpoints:

  • POST /api/v1/auth/register - Register new user
  • POST /api/v1/auth/login - Authenticate and obtain JWT access token
  • GET /api/v1/users/me - Retrieve current user profile
  • GET /api/v1/tasks/ - List user tasks with pagination and status filtering
  • POST /api/v1/tasks/ - Create new task
