# Decodelabs Task Flow Backend

Production-grade, fully tested, secure, and deployment-ready RESTful Task Management API built with Python (FastAPI), Async SQLAlchemy, Alembic, PostgreSQL (Neon), Argon2, JWT, and Docker.

## Project Status
Currently completed **Phase 4.3 & 4.4** (OAuth2PasswordBearer scheme and `get_current_user` / `get_current_active_user` authentication dependencies implemented in `app/core/deps.py`).
Follows the 10-phase implementation plan outlined in `PLAN.md`.
